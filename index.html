📦 安装步骤

1确认你装了 Fabric Loader 0.19.5+（1.20.1）
2把 bunkerconsole-2.3.2.jar 放进 .minecraft/mods/ 文件夹
3还要放一个 Fabric API（fabric-api-0.92.12+1.20.1.jar），没有这个 mod 跑不起来
4启动游戏，进入世界

🎮 游戏内操作速查

操作方式
拿配置魔杖/give @s bunkerconsole:configurator
拿光源方块/give @s bunkerconsole:glow_block
打开控制台按 K 键
配置展示框手持魔杖 → 右键展示框 → 输入物品 ID
设土豆箱手持魔杖 → 右键箱子方块
设发射器（自动装填）手持魔杖 → 右键发射器方块
设红石信号位置手持魔杖 → 右键其他方块
设选区（备份范围）K → 进入选区模式 → 魔杖右键两个对角
设出生点站在位置上 → K → 点「设为当前位置」
手动触发重置/bunker reset
固化模板（备份选区）K → 点「固化模板」
查看当前状态/bunker status
调试信息/bunker debug

🗺️ 设置备份选区

1先把生态圈/场景建好
2按 K 打开控制台，点「进入选区模式（魔杖右键两个角）」
3拿魔杖：/give @s bunkerconsole:configurator
4右键你要备份区域的第一个角（聊天栏提示"角点1已设置"）
5右键对角点（自动保存选区范围，提示选区坐标）
6再按 K → 点「固化模板（备份当前场景）」
💡 v1.6.1 起改用 Java API 直接复制方块，不再依赖 clone/fill 命令，100% 可靠。

🔧 配置展示框

1拿魔杖：/give @s bunkerconsole:configurator
2手持魔杖，对着后墙上的展示框 右键
3弹出输入框，输入物品 ID，例如：
minecraft:wheat
minecraft:iron_ingot
minecraft:diamond
4点「保存配置」，自动写入配置文件

📦 土豆箱跨轮回储物

1拿魔杖，在地图中心附近放一个普通箱子
2手持魔杖，对着箱子方块 右键
3聊天栏提示「土豆箱已设置: x,y,z」
💡 以后每次重置，这个箱子里的东西都会自动备份并恢复，不会被清空。

🧨 发射器自动装填

✨ 新功能 v1.7.0 — reset 后自动往发射器填烟花火箭+火药，自动清掉落物
1拿魔杖，对着你那个发射器方块 右键
2聊天栏提示「自动装填发射器已设置: x,y,z」
3以后每次 reset 后，发射器自动清空并填入：
  • 第1格：烟花火箭 ×1
  • 第2格：火药 ×1
💡 同时 reset 会自动清除选区范围内所有掉落物，解决发射器/箱子内容物变成掉落物的问题。

📡 红石信号位置

✨ 新功能 v1.5.0 — 魔杖右键任意方块设置红石块生成位置
1在你想要放红石块的位置，用魔杖右键那个方块
2聊天栏提示「红石信号位置已设置: x,y,z」
3手动把那个位置的方块拆掉
4所有展示框物品凑齐后，mod 自动在这个位置生成红石块

⏱️ 头顶倒计时

✨ 新功能 v1.6.0 — 屏幕上方实时显示剩余时间

游戏内屏幕上方（actionbar 位置）每秒显示：

  • 超过 1 分钟：第1天 | 剩余 4分32秒（绿色）
  • 10~60 秒：第1天 | 剩余 45秒（黄色）
  • 10 秒以内：第1天 | 剩余 8秒（红色，提醒快重置了）

⚠️ 常见问题

Q: 游戏启动崩溃？
A: 检查有没有装 Fabric API。这个 mod 依赖 Fabric API，没有必崩。
Q: 魔杖右键展示框没反应？
A: 确认你手持的是 bunkerconsole:configurator，右键展示框实体（不是方块）。
右键箱子 = 设土豆箱；右键发射器 = 设自动装填发射器；右键其他方块 = 设红石信号位置。
Q: 怎么改一天的时长？
A: 用命令 /bunker setTimer 3000，单位是刻（20刻=1秒）。3000=2.5分钟，6000=5分钟。
Q: reset 后场景不对？
A: 先跑 /bunker debug 看活动区和模板区 corner1 位置的方块。如果模板区是空气，说明你固化模板时场景是空的——先建好场景，再进选区模式圈范围，最后点「固化模板」。
Q: reset 后发射器里的东西变成掉落物了？
A: v1.7.0 起会自动清掉落物，并自动往魔杖设置过的发射器里填烟花火箭+火药。
Q: 选区选错了怎么办？
A: 按 K → 点「进入选区模式」重新圈两个角就行，会自动覆盖旧选区。
