📦 安装步骤

1确认你装了 Fabric Loader 0.19.5+（1.20.1）
2放一个 Fabric API（fabric-api-0.92.12+1.20.1.jar），没有这个 mod 跑不起来
3放前置 mod Immersive Portals（IP）5.2.0-mc1.20.1。透视门、跨维无缝传送、动态建维度都依赖它；客户端和服务端都必须安装。可在 Modrinth 搜 Immersive Portals，选 1.20.1 对应版本下载
4把 bunkerconsole-2.5.0.jar 放进 .minecraft/mods/ 文件夹
5启动游戏，进入世界
缺少 IP 前置会直接拒绝加载本 mod。传送门透视、走进无感跨维、游戏内新建关卡维度这三项能力由 IP 提供，本 mod 只负责建门、绑定与维度编排。

🗺️ 设置备份选区

1先把生态圈/场景建好
2按 K 打开控制台，点「进入选区模式（魔杖右键两个角）」
3拿魔杖：/give @s bunkerconsole:configurator
4右键你要备份区域的第一个角（聊天栏提示"角点1已设置"）
5右键对角点（自动保存选区范围，提示选区坐标）
6再按 K → 点「固化模板（备份当前场景）」
💡 v1.6.1 起改用 Java API 直接复制方块，不再依赖 clone/fill 命令，100% 可靠。

🔧 配置展示框

1拿魔杖：/give @s bunkerconsole:configurator
2手持魔杖，对着后墙上的展示框 右键
3弹出输入框，输入物品 ID，例如：
minecraft:wheat
minecraft:iron_ingot
minecraft:diamond
4点「保存配置」，自动写入配置文件

📦 土豆箱跨轮回储物

1拿魔杖，在地图中心附近放一个普通箱子
2手持魔杖，对着箱子方块 右键
3聊天栏提示「土豆箱已设置: x,y,z」
💡 以后每次重置，这个箱子里的东西都会自动备份并恢复，不会被清空。

🧨 发射器自动装填

✨ 新功能 v1.7.0 — reset 后自动往发射器填烟花火箭+火药，自动清掉落物
1拿魔杖，对着你那个发射器方块 右键
2聊天栏提示「自动装填发射器已设置: x,y,z」
3以后每次 reset 后，发射器自动清空并填入：
  • 第1格：烟花火箭 ×1
  • 第2格：火药 ×1
💡 同时 reset 会自动清除选区范围内所有掉落物，解决发射器/箱子内容物变成掉落物的问题。

📡 红石信号位置

✨ 新功能 v1.5.0 — 魔杖右键任意方块设置红石块生成位置
1在你想要放红石块的位置，用魔杖右键那个方块
2聊天栏提示「红石信号位置已设置: x,y,z」
3手动把那个位置的方块拆掉
4所有展示框物品凑齐后，mod 自动在这个位置生成红石块

🌀 透视传送门与关卡维度（接入 Immersive Portals）

✨ v2.5.0 — 传送门改为 IP 透视门：站在门前能直接看到对面维度的实时画面；走进门完全无感跨维，无加载屏；支持在游戏内动态新建关卡维度。

三种能力

👁️

隔门透视

IP 门实时渲染对面维度视角，站在门前即可看到门后场景，无需进门。

🚶

无感穿越

走进门即完成跨维度传送，不弹原版维度切换加载屏，双向门自动配对。

🌍

动态建维

游戏内用命令新建关卡维度，地形/生物群系预设与主世界一致，建好即可绑门。

预留关卡维度

mod 内置两个预留静态关卡维度 bunkerconsole:level2、bunkerconsole:level3，世界预设与主世界相同（overworld 地形/生物群系预设）。这些维度为静态关卡，不参与每日重置循环；第一关主世界 minecraft:overworld 沿用原有重置逻辑。传送门可绑定到任意一个预留关卡或新建维度。

放置与绑定传送门

1拿传送门方块：/give @s bunkerconsole:portal_block，在主世界放一扇门
2到目标关卡（level2 / level3 或新建维度）再放一扇门
3手持配置魔杖，右键第一扇门，聊天栏提示「传送门 A 已记录」
4再右键目标维度的第二扇门，提示「传送门已双向绑定」，两扇门建立配对，IP 透视门随即生成
5站在门前即可看到对面视角；走进任意一扇已绑定的门，即无缝传送到配对门所在维度与坐标

动态新建关卡维度

1在聊天栏输入命令（ID 可带命名空间，不带则默认 bunkerconsole:）： 
/bunker createlevel level4
/bunker createlevel bunkerconsole:level5
2新维度复用主世界的维度类型与地形生成器，生成后即可在里面放门、用魔杖绑定
3输入 /bunker levels 查看全部关卡维度与当前传送门绑定列表
💡 绑定关系自动写入配置文件 portalLinks，重启世界后保留；服务端启动时会按配置自动重建所有 IP 透视门。

⚠️ 常见问题

Q: 游戏启动崩溃 / mod 被拒绝加载？
A: 依次检查：① 装了 Fabric API；② 装了 Immersive Portals 5.2.0-mc1.20.1（客户端+服务端都要）；③ Fabric Loader 与 MC 版本为 1.20.1。本 mod 把 IP 列为强制前置，缺 IP 会直接拒绝加载。
Q: 魔杖右键展示框没反应？
A: 确认你手持的是 bunkerconsole:configurator，右键展示框实体（不是方块）。
右键箱子 = 设土豆箱；右键发射器 = 设自动装填发射器；右键其他方块 = 设红石信号位置。
Q: 怎么改一天的时长？
A: 用命令 /bunker setTimer 3000，单位是刻（20刻=1秒）。3000=2.5分钟，6000=5分钟。
Q: reset 后场景不对？
A: 先跑 /bunker debug 看活动区和模板区 corner1 位置的方块。如果模板区是空气，说明你固化模板时场景是空的——先建好场景，再进选区模式圈范围，最后点「固化模板」。
Q: reset 后发射器里的东西变成掉落物了？
A: v1.7.0 起会自动清掉落物，并自动往魔杖设置过的发射器里填烟花火箭+火药。
Q: 选区选错了怎么办？
A: 按 K → 点「进入选区模式」重新圈两个角就行，会自动覆盖旧选区。
